Ein Chip, drei Links

Ein normaler NFC-Aufkleber hat einen festen Link gespeichert. Ein dynamischer NFC-Chip hat zusätzlich eine Verbindung zu einem Mikrocontroller. Der kann den gespeicherten Link jederzeit überschreiben, auch während der Aufkleber schon irgendwo klebt. In unserer Demo entscheidet die Lage der Platine, welcher Link gerade im Chip steht: hochkant, quer oder kopfüber ergibt jeweils einen anderen Link.

Was im Chip passiert

Beim Drehen der Platine

  1. Lage messen: Der Lagesensor misst, in welche Richtung die Schwerkraft zeigt.
  2. Lage erkennen: Der Mikrocontroller wertet das aus und erkennt hochkant.
  3. Link schreiben: Er schreibt über eine Datenleitung Link 1 in den Speicher des NFC-Chips.
  4. Bereit: Der Chip hält den neuen Link bereit, bis ein Handy ihn ausliest.

Beim Auslesen mit dem Handy

  1. Magnetfeld: Das Handy erzeugt mit seiner Antenne ein magnetisches Wechselfeld (13,56 MHz).
  2. Energie: Das Feld erzeugt in der Antennenspule des Chips eine Spannung. Damit ist der Chip ohne Batterie mit Strom versorgt.
  3. Anfrage: Das Handy verändert das Feld in einem bestimmten Muster und schickt so die Anfrage „Was ist gespeichert?“.
  4. Antwort: Der Chip antwortet, indem er das Feld minimal belastet. Das Handy erkennt diese Schwankungen als den gespeicherten Link.
  5. Anzeige: Das Handy zeigt den Link an.

Kaffee per NFC bestellen

Bisher hat das Handy nur gelesen. NFC funktioniert aber in beide Richtungen: Das Handy kann auch Daten an den Chip schicken, und der Mikrocontroller dahinter kann antworten. In der Demo wählst du in der App einen Kaffee, hältst das Handy an die Maschine, und die Maschine bekommt die Bestellung und meldet zurück, wenn der Kaffee fertig ist.

Kaffee-App

Was darf's sein?

Datenweg

  1. Verbindung: Das Handy baut das Magnetfeld auf, der Chip wird darüber mit Strom versorgt.
  2. Bestellung senden: Das Handy schickt die Kaffeeart über das Feld in die Mailbox, einen kleinen Zwischenspeicher im Chip.
  3. Bescheid geben: Der Chip meldet dem Mikrocontroller der Maschine über eine eigene Signalleitung, dass eine Nachricht da ist.
  4. Abholen: Der Mikrocontroller liest die Bestellung über eine Datenleitung aus der Mailbox.
  5. Zubereiten: Die Maschine brüht den gewählten Kaffee.
  6. Antwort ablegen: Der Mikrocontroller legt die Rückmeldung „fertig“ in die Mailbox.
  7. Antwort lesen: Das Handy holt die Rückmeldung über das Feld ab und zeigt sie in der App an.

Zusätzliche Funktionen eines NFC Chips

Fast Transfer Mode (FTM)

Der Chip hat zwei Arten von Speicher. Das EEPROM behält Daten auch ohne Strom, zum Beispiel den Link aus der ersten Demo. Das Schreiben ist aber langsam: Jeder kleine Block von 4 Byte braucht einige Millisekunden, und jede Speicherzelle verträgt nur eine begrenzte Zahl an Schreibvorgängen.

Im Fast Transfer Mode nutzt der Chip stattdessen einen SRAM-Puffer von 256 Byte, die sogenannte Mailbox. SRAM lässt sich sofort und beliebig oft beschreiben, verliert die Daten aber, sobald der Strom weg ist. Die Mailbox ist deshalb kein Speicher, sondern eine Übergabestelle.

  1. Ablegen: Das Handy schreibt eine Nachricht über das Funkfeld in die Mailbox.
  2. Melden: Der Chip markiert die Mailbox als belegt und gibt dem Mikrocontroller über die Signalleitung Bescheid.
  3. Abholen: Der Mikrocontroller liest die Nachricht über die Datenleitung aus. Danach ist die Mailbox wieder frei.
  4. Rückweg: Genauso funktioniert es umgekehrt: Der Mikrocontroller legt eine Nachricht ab, das Handy holt sie ab.

Größere Datenmengen, zum Beispiel ein Firmware-Update, werden in 256-Byte-Pakete aufgeteilt und nacheinander durch die Mailbox geschickt.

Energy Harvesting (EH)

Das Magnetfeld des Handys überträgt nicht nur Daten, sondern auch Energie. Normalerweise nutzt der Chip davon nur so viel, wie er selbst braucht. Mit Energy Harvesting gibt er den Rest an einem eigenen Pin nach außen ab.

  1. Induktion: Das Wechselfeld des Handys (13,56 MHz) erzeugt in der Antennenspule des Chips eine Wechselspannung.
  2. Gleichrichten: Der Chip wandelt sie in eine Gleichspannung um und versorgt damit zuerst sich selbst.
  3. Ausgeben: Die übrige Energie stellt er am EH-Pin bereit, als Spannung von wenigen Volt.
  4. Nutzen: Daran kann eine kleine Schaltung hängen, etwa eine LED, ein Sensor oder ein sparsamer Mikrocontroller. Sie läuft, solange das Handy in der Nähe ist, ganz ohne Batterie.

Wie viel Energie ankommt, hängt stark vom Abstand ab: Die magnetische Kopplung zwischen den beiden Antennen nimmt mit jedem Zentimeter deutlich ab. Probier es rechts aus.
